*Mental Model 
- 1943 // 인지심리학 
- 보통의 일반적인 사람들이 어떤 행동과 행위 실행 -> 상식적인 선에서 어떤 단계와 과정을 거칠것이야
- 여성 : 온라인 쇼핑몰 : 화장품 구매 : 고관여 : 검증(내가 피해x) 
- 검증/인정 => 브랜드화 되어진거 
- 효능
- 신뢰
- 구매 

*Kano Model 
- 노리아키 카노 // 일본 경영학 박사
- 1984
- 사용자는 어떤 소비재 또는 상품에 노출되었을 때 3가지 단계별 만족도를 느낀다 
- Must-Be : 비비크림을 바르는 이유(잡티, 커버, 지속)
- Performance : 24시간
- Attractive : 예상치 못한 가치 부여 


*Miller's Law
- 조지 밀러, 인지심리학자, 1956
- 스티브잡스 
- 2008, 아이폰 3 출시 : phone, internet, ipod
- 소비자들에게는 많은 정보를 줘봐야 의미가 없다.
- 확실한 요소 몇 가지 만으로도 충분히 기억에 오래 남는다 
- 3~5개 

*Hick's Law
- 1953, 실험심리학
- 결국 소비재를 판매하는 기업 입장에서 모든 메세지의 귀결은 상품 구매 및 미구매로 결정 
- 매장에서 구매하세요 
- 너무 많은 선택지를 주면 구매 결정을 못한다(구매 결정 장애) 

*Jakob's Law
- 2000 // 웹 사용성 분석 
- 소비자들은 웹에서 어떤 것을 먼저보며, 또 어떤 상황에서 어떤 정보가 제공되는지에 대해 어느정도 선행
학습이 되어있고, 또 해당 학습을 통해서 미리 어느정도 유추를 하더라

*Fitts's Law
- 1954 // 인간공학 
- 사람은 가까이있고, 상대적으로 큰 요소를 먼저 보거나 선택하고, 순차적으로 시선이 이동한다. 

* Von Restorff Effect
- 실험 심리학
- 동일한 요소들 가운데, 차별화 되어있는 요소가 존재한다면, 상대적으로 가독성이 높아지는 효과

*Gestalt Theory
- 심리학
- 어떤 요소들이 비슷한 위치에 비슷한 형태를 띄고 있으면 해당 요소를 그룹화해서 사람들은
오랜 시간 동안 기억한다
