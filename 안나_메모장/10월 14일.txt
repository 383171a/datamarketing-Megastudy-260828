pipeline : 
1) 데이터 정제 (Data Cleansing)
> 데이터 전처리 (데이터를 분석할 수 있는 형태로 바꾸는 작업 등을 포함한 전체 과정) 
- 정제 (Cleansing) : NaN, Null = > 삭제하던지 대체하던지 // 불필요하거나 비효율적인 값이
입력되어있을 때 수정
- 변환 => 형변환
- 가공 
- 정규화
- 구조화

2) 데이터 검증 (Data Validation)
- 스파이더 = 크롤러가 데이터를 수집해서 아이템즈에 사전에 생성해놓은 필드 안에
값을 입력하려고 할 때, 사전에 정의해놓은 데이터 타입과 일치하는지 여부 등을 사전에 검증

3) 중복 데이터 제거 (Deduplication)
- 만약 이미 입력된 데이터가 존재한다면, 굳이 또 동일한 데이터를 저장할 필요가 없음 
=> 사전에 입력된 값을 유지

4) 데이터 후처리 (Post Processing) 
- 어떤 작업을 끝내고, 해당 작업 이후에 또 다른 작업이 이어서 진행될 수 있도록 순서를 정의하는 역할
